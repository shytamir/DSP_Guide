# YELLOW and PURPLE Problem Resolvers — Deferred Indefinitely

**Historical status:** This unplanned concept was explicitly deferred
indefinitely on 2026-08-27. It did not authorize design or implementation and
was never part of an active roadmap.

At deferral, the concept described optional problem-resolver guidance for the
YELLOW and PURPLE phases. Candidate subjects included Geothermal Extraction,
High-Speed Assembling, Proliferator and carried-fuel upgrades, Research Speed,
Integrated Logistics, and cargo-stacking tools.

The unresolved decision surfaces were:

- which phase would have owned each subject;
- what reader problem each recommendation would have solved;
- teaching depth and placement;
- whether any compact Quick process would have been justified; and
- how optional advice would have remained separate from phase gates and
  discardable research recommendations.

Existing guide text was not approved as a model for this concept.

Any reconsideration would require explicit owner reactivation and a new
governed record. Nothing in this historical concept defines current work.

## Review addendum — 2026-10-11

The owner requested that these recommendations be retained alongside the
concept while keeping it deferred indefinitely. They are discussion inputs,
not approved requirements or authorization to plan or implement this concept.

### Findings and recommendations

Select observable reader problems first, then admit only technologies that
solve them. Preserve the distinction between situational remedies, the ordered
but discardable research queue, and the three-continuously-supplied-Labs exit
condition in each phase. The accepted NR-07 and NR-08 stories deliberately
excluded these resolvers; their research lists do not approve this concept.

| Candidate | Existing overlap and decision needed |
| --- | --- |
| Geothermal Extraction | RED already recommends a Geothermal Power Station on a cleared base site. Identify the intended power problem, phase ownership, and applicability when combat guidance is hidden. |
| High-Speed Assembling | PHOTON already introduces it for lines struggling with WHITE's pace. Identify the earlier observable need and how later guidance handles prior completion. |
| Proliferator upgrades | The [optional proliferation reference](../../../index.html#ref-proliferation) explains modes and tradeoffs. Decide between a contextual link, a specific upgrade recommendation, and additional instruction. |
| Carried-fuel upgrades | Hydrogen Fuel Rod already appears in ILS research. Identify the carrying, travel, or energy problem and the appropriate fuel tier. |
| Research Speed | Distinguish limited research capacity from inadequate cube supply, then establish an appropriate stopping rank. |
| Integrated Logistics and cargo stacking | The [Pile Sorter reference](../../../index.html#ref-pile-sorter) already addresses port and belt constraints. Define whether the concept covers this capability alone or additional stacking tools. |

Before any future planning, settle:

1. The observable problem that earns each recommendation.
2. Each subject's phase ownership, authoritative availability, and handling of
   earlier optional research that the reader may have skipped.
3. Teaching depth: symptom, action, tradeoff, and stopping condition; add a
   Quick process only where operation needs procedural explanation.
4. Placement: visible phase prose, expandable guidance, or a link to one
   canonical optional reference. Existing text is not an approved template.
5. Clear separation from filler queues and phase gates so that optional
   remedies do not become another completion checklist.

This review did not select a final subject list, audit new prerequisites or
stopping ranks, approve a presentation, or change the guide.
