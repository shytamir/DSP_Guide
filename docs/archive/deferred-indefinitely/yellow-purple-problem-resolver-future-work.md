# YELLOW and PURPLE Problem Resolvers — Deferred Indefinitely

**Historical status:** This unplanned concept was explicitly deferred
indefinitely on 2026-08-27. It did not authorize design or implementation and
was never part of an active roadmap.

At deferral, the concept described optional problem-resolver guidance for the
YELLOW and PURPLE phases. Candidate subjects included Geothermal Extraction,
High-Speed Assembling, Proliferator and carried-fuel upgrades, Research Speed,
Integrated Logistics, and cargo-stacking tools.

The unresolved decision surfaces were:

- which phase would have owned each subject;
- what reader problem each recommendation would have solved;
- teaching depth and placement;
- whether any compact Quick process would have been justified; and
- how optional advice would have remained separate from phase gates and
  discardable research recommendations.

Existing guide text was not approved as a model for this concept.

Any reconsideration would require explicit owner reactivation and a new
governed record. Nothing in this historical concept defines current work.
