# Dark Fog Control and RED Gate — Deferred Indefinitely

**Historical status:** This unplanned concept was explicitly deferred
indefinitely on 2026-08-27. It did not authorize design or implementation and
was never part of an active roadmap.

At deferral, the concept described an enabled-by-default COMBAT/PEACE control
that would have shown or hidden the guide's bounded Dark Fog recommendations,
together with reconciliation of those conditional recommendations and RED's
completion gate.

The unresolved decision surfaces were:

- placement and visible labels;
- state behavior and persistence;
- affected guide content;
- accessibility behavior; and
- the relationship between optional Dark Fog guidance and phase completion.

The guide retained its bounded RED-phase Dark Fog contract. Later Dark Fog
progression, farming, drops, space combat, Relay Stations, hives, and concealed
technologies remained outside scope.

Any reconsideration would require explicit owner reactivation and a new
governed record. Nothing in this historical concept defines current work.

## Review addendum — 2026-10-11

The owner requested that these recommendations be retained alongside the
concept while keeping it deferred indefinitely. They are discussion inputs,
not approved requirements or authorization to plan or implement this concept.

### Findings and recommendations

- The introduction already makes Dark Fog guidance conditional, but RED's
  [Security Mall](../../../index.html#card-red-security-mall) is marked
  MANDATED and its supplies must be stocked before ILS. RED's dashboard,
  completion condition, and default checklist instead require sustained red
  science and flowing refinery outputs. Settle that relationship before
  designing a visibility control.
- Prefer preserving the science completion gate and making defense preparation
  explicitly conditional. Decide separately whether stocking defenses and
  clearing a base are recommendations, preparations before ILS, or completion
  requirements; none of those choices is approved by this review.
- Prefer wording that describes guide visibility, such as "Show Dark Fog
  guidance," over COMBAT/PEACE labels that could be mistaken for game settings.
  Placement and the historical enabled default still need confirmation.
- Define the entire affected content set together: opening orientation,
  combat-specific research, Security Mall, the
  [clearing procedure](../../../index.html#red-planetary-base-clearing), the
  [ILS](../../../index.html#ils) reminder, and the
  [WARP](../../../index.html#warp) combat loadout. Decide whether hidden advice
  retains an explanatory entry point.
- Decide whether the preference persists locally across reloads and remains
  independent of checklist reset. Specify keyboard and screen-reader behavior,
  direct links into hidden content, and scripting/storage fallbacks.
- Crystal Smelting is introduced in RED specifically for Signal Towers.
  Making that instruction conditional requires checking later research and
  recipe assumptions against retained data for both reader routes.

The existing bounded combat coverage remains the scope. This review did not
validate a new conditional route, change the guide, or expand combat coverage.
