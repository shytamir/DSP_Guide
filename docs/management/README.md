# Management Records

This directory contains active permission and governance records that affect
what the project may publish.

## Current records

- `game-asset-use-permission-sanitized.md` preserves the limited permission to
  use unmodified in-game assets in the non-commercial guide and related mod.
- `bootstrap-blue-unification-user-stories.md` records the approved structural
  and editorial work for combining the guide's two opening phases.
- `guide-icon-integration-plan.md` preserves the implemented scope and
  validation contract for the static prototype-icon pass. Its authoritative
  binding map remains external in the DSP Guide Check mod repository.
- `asset-map-corrections-and-followups.md` records the exact upstream map
  corrections used by the guide; all guide-side follow-ups are complete.
- `dark-fog-red-defense-user-stories.md` records the approved, tightly bounded
  RED-phase defense guidance and its two active implementation stories.

Raw correspondence, unsanitized personal information, player snapshots, and
game assemblies must remain outside version control.
