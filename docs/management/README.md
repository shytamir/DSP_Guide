# Management Records

This directory contains active permission and governance records that affect
what the project may publish.

## Current records

- `game-asset-use-permission-sanitized.md` preserves the limited permission to
  use unmodified in-game assets in the non-commercial guide and related mod.

Completed plans, correction records, and user stories were moved to
[`../archive/`](../archive/). Their preserved implementation language is
historical and does not define current work.

Raw correspondence, unsanitized personal information, player snapshots, and
game assemblies must remain outside version control.
