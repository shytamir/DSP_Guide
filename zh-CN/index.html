实用流程指南

从第一座工厂到「」的实用路线

我是在学习 DSP 的过程中写下这份指南的。每次完成一项建设后，我常常不知道下一步该做什么。你可以一边玩一边查阅，不必从头读到尾，更不用把内容背下来。

对我来说，最管用的节奏是：

查阅指南 → 玩一会儿 → 需要理清方向时再回来 → 找到下一件值得做的事 → 回到游戏

默认路线是：

蓝糖 → 红糖 → 星际物流 → 黄糖 → 紫糖 → 绿糖 → 戴森云 → 光子 → 白糖 → 任务完成

DSP 中的每种矩阵都有正式名称，但忙着建设时，用颜色来区分更直观。通常我们会这样简称：

科技树中要点击的科技使用游戏内的正式名称。正文讨论实际生产的物品、速率、库存和配方时，通常用蓝糖等颜色简称；物品标签（包括卡片和表格中的名称）则保留游戏内的正式名称。

上面的路线力求简单，但并不是唯一值得做的事。默认用太阳帆组成的戴森云来实现光子生产和白糖科研。如果想建造能长期保留的工程，再去造戴森球；没有永久性的戴森球也能完成这条路线。

如果启用了黑雾，红糖阶段会帮助你守住初始星球，并清除一处本地基地。当前的战斗先做到这里，其余的就暂且留在迷雾中吧。

途中还会遇到一些实用的支线项目。先不必理会；等它能解决眼前的问题时，再来了解也不迟。

如何使用本指南，而不用反复重读

玩了很久，忘了该往哪走？用右侧彩色导航条跳到当前阶段，让当前位置帮你回忆。这正是它的用途。

生产卡片的默认条件

除非操作说明另有注明，卡片均使用常规配方，不替换稀有资源，也不使用增产剂。

卡片的用途：卡片是可按需查阅的生产概览。指南说明当前什么最重要、为什么重要；卡片则展示一条实用产线的完整结构，不要求你按图精算内部机器数量。

卡片的结构：原料供应列出原始或已建立供应的输入。生产流程按建设顺序展示各条短支线及其汇合点。产出去向说明准确的成品目标和用途。副产物只列出确实能再利用、或可能堵住产线的副产物类型。只有会影响建设或持续运行的事项，才会出现在操作说明中。

有限批次、出行物资、研究投入、航线配置和轨道运行仍在阶段正文中说明。内部精确消耗速率、机器和传送带数量、装满时间及产能余量，则留给实际建成的工厂来决定。

有目的地留库存：建筑超市成品、远征物资、会堵塞生产的副产物，以及阶段性批次，都适合存入有明确上限的仓储。每条线后面都接巨量库存，反而可能把短缺掩盖到整座工厂一起停摆；普通中间产物只需留出足够空间，让运输和生产顺畅运转。

仓储上限按格设置：仓储滑块开放的是完整的堆叠格，而不是精确的物品数量。卡片会说明开放格数及其最大容量。若目标少于一整组，请在达到数量时暂停生产机器。

术语表 — 工厂里常用的说法
阶段
主线中一个实用的步骤单元。每个阶段描述下一项要建立的能力；工厂条件允许时，可以同时推进多个阶段。
建筑超市
一组小型生产线，把常用建筑和物流部件存入有上限的仓储，让伊卡洛斯不必反复手工制作。
产线
由原料供应、加工和输出连接而成的完整路径，用于自动生产一种实用成品。
支线
较大产线中，负责某一种原料的生产路径。
汇合点
两条或更多原料支线汇入同一道配方的位置。
缓冲库存
有上限的储存空间，用于应对中断或保存计划好的批次。它提供的是周转余地，不是把所有箱子都装满的理由。
供给端／供应
提供物品，让配送运输机、物流运输机或星际物流运输船前来取货的物流设置。
接收端／需求
请求配送运输机、物流运输机或星际物流运输船送来物品的物流设置。
兜底供应
只有优先供给跟不上时，才补足缺口的备用来源。
有效发射时间占比
电磁轨道弹射器实际发射的时间占比；其余时间因轨道角度不合适而等待。

目标

第一个正式阶段有两项相辅相成的任务。先建建筑超市，让基础物资在箱子里等着你，不再把时间花在反复手搓上。超市本来就要生产蓝糖所需的部件，因此用同一座逐步扩大的工厂，让蓝糖科研也自行运转。两项都完成后，再进入下一阶段。

不用等到所有东西都能造时才动工。超市的每一部分，都可以在相应配方解锁后立即开建。首批仓储会自行补货，同时用蓝糖解锁火力发电、钢材和地基。

别为了自动化所有已解锁配方而在这里停留太久。以后等待科技研究完成时，还有很多空当可以用来补建。

这条开局科技链让工厂具备运输、冶炼和制造的基本能力。随着建筑超市成形，再补上和。等箱子补货时，也可以研究不消耗矩阵的实用升级：让伊卡洛斯能携带更多物资；则让建设时不必频繁调整站位。

速查 — 多少才够用

平常建设只需从限量仓储中取出传送带、分拣器、采矿机、熔炉、制造台、仓储和供电设备，而不再临时手搓救急，就说明建筑超市已经就绪。你去忙别的事时，让这些箱子自行补货。

电磁矩阵产量达到 20/min，就能推动初期科研；做到40/min会更从容，值得一步建好。初期供电以大约15–20 MW为目标。八座火力发电厂配合工厂已有的风力涡轮机，在这个阶段很实用。继续用超市产出的设备扩建风电网络：不消耗燃料的基础发电量，能在煤矿运输出问题时给工厂留些余地。

目标

对撞机路线最容易搭建和理解，代价是大量消耗氢和电。因此，下面的产线会把多余重氢做成燃料，为自身扩张提供电力。

同步扩充重氢、奇异物质和电力

从一座容易观察的储液罐向重氢对撞机供料。它们消耗很快，尤其是在量子芯片产线也用氢的时候。如果罐内库存持续下降，先加强氢供应，再添对撞机。

生产出的重氢优先送去制造奇异物质。同一条传送带继续接到一条氘核燃料棒产线，确保只有剩余重氢才会变成燃料。将成品燃料棒存放在容易查看的位置，先积累一批，再依靠它们供电。

供料优先级：先供应奇异物质；剩余重氢再转为可观察的燃料库存。

速查 — 多少才够用

根据实际运行情况决定扩产或前进。观察弹射器的实测发射时间占比、太阳帆库存升降、戴森系统实时发电量，以及射线接收站的实际产出。接收站已能有效工作，就开始光子阶段；只有发射时间、太阳帆库存或接收站需求显示出短缺时，才在对应位置继续扩建。

在发射网络达到完整规模前，研究太阳帆寿命等级 1 → 等级 2。升级让每张太阳帆在轨道上停留更久，减少工厂和弹射器需要补充的数量。也可以跳过升级，用更多太阳帆产能和成功发射次数来补偿。这种取舍合理，具体怎么算可以自行决定。

完成两级太阳帆寿命升级后，参考戴森云需要建成405/min 的太阳帆产能，并实现约383/min 的成功发射速率。六十台弹射器若平均有 32% 的时间在发射，就能达到约 384/min。这是规划参考，不是完成条件：弹射器只有在轨道和发射窗口允许时，才能真正贡献发射量。

把参考值当作起点。够不够用，最终取决于实际建成的工厂和所处的恒星。

参考规模的戴森云建成之前，接收站阵列就能开始积累反物质。让它持续运行，同时扩大戴森云，并在光子阶段强化系统。之后存够 2,000 个反物质才进入白糖阶段；不要为等这个库存而停留在戴森云阶段。通过接收站与反物质过渡环节继续前进。

3. 自动化运输船路线

开始条件：引力矩阵已支持高效翘曲器配方，运输船引擎也已研究到等级 4。完成条件：母星已供电的星际物流站使用运输船和翘曲器，从远端供应站自动取货，不再需要伊卡洛斯运送。

研究后，高效配方可将一个引力矩阵制成八个空间翘曲器。把引力矩阵送入一台制造台，将产出的翘曲器送入设为蓝色本地供应的行星内物流运输站，装入物流运输机，让它们通过母星星际物流站中设为橙色本地需求的物品栏补货。星际物流站会自动把前 50 个移入翘曲器专用储备栏。

然后继续研究。远端星际物流站仍不供电，把稀有资源设为星际供应。母星端将同一资源设为星际需求，装入运输船，并给这座已供电的站补充翘曲器。母星船队会往返取货，无需前哨发船。

长途路线仍然供不上？运输船运载量升级能让每艘船带回更多材料。它能显著改善远程运输，但不是启用路线的必要条件。

[集装分拣器] — 集成物流

用途

快速搬运并堆叠同类货物，让传送带和机器接口不再成为瓶颈。集装分拣器改善的是运输，不会缩短机器内部的配方加工时间。

适用情况

  • 配方所需机器已足够，但密集布局仍在接口处断料或堵塞；
  • 堆叠能腾出实用的传送带运力；
  • 高吞吐循环线，包括分馏塔循环线，能从更密集的同类货物中受益。

做法

实测表明进料或传送带吞吐量受限时，再使用集装分拣器。它堆叠的是同一种物品，不能把混合货物堆在一起；混料传送带的设想还是另找地方尝试。

何时返回主线

货物搬运不再拖慢产线后，就保持现有机器不动，继续推进。

[气态巨星] — 轨道采集器

用途

在本地生产足够的氢、重氢或可燃冰开始得不偿失时，考虑轨道采集器。

适用情况

  • 氢确实拖慢了卡西米尔晶体或绿糖生产；
  • 本地生产足量重氢占用了太多工厂资源；
  • 可燃冰能明显简化石墨烯生产；
  • 实际能到达的气态巨星，以实用的速率提供所需资源。

做法

投入设备前，先查看巨星列出的资源和采集速率。每台采集器都独立采集其显示的资源；随着矿物利用升级，采集能力也会提高。

在消耗端工厂，优先使用本地产生的副产氢，由轨道采集器兜底。一种简单做法是分成两路接收：一路接收原油精炼厂、可燃冰和反物质生产的副产物，另一路允许从采集器输入。合并传送带时，把副产物一路设为优先输入。星际物流站的优先配对或分组，也可以跨行星维持同样的优先顺序。无论采用哪种方法，都要让副产物出口便于观察，免得储罐满了，悄悄卡住另一条产线。

⚠ 气体储罐满了，不一定代表供应充裕。也可能是输入的氢掩盖了本地副产物堵塞。扩建采集器之前，先查清究竟是哪一路填满了目的地。

何时返回主线

气体供应不再拖慢绿糖或后续生产时，就返回主线。

[星际输电] — 能量枢纽与蓄电器运输

用途

一颗星球电力富余，而另一颗星球通过物流获得电力比建立自有燃料链更方便时，就可以使用这套系统。

建立循环

  1. 在发电星球，将空的蓄电器送入设为充电的能量枢纽。
  2. 通过星际物流输出蓄电器（满）。
  3. 在远端星球，把它们送入设为放电的能量枢纽。
  4. 通过第二个物流物品栏送回空的蓄电器，让同一批设备不断循环。
⚠ 放电优先供给电网。即使本地发电机足以承担负荷，放电中的能量枢纽也可能消耗输入电力。目的地同时使用外来电力和本地发电时，应为放电阵列配上等规模的充电阵列：多余的放电立即充回空蓄电器，只有本地电网的实际缺口，才消耗外来电量。

空蓄电器回运也是电站的一部分，不能当成善后工作。在充电星球，应优先接收回运的空蓄电器，再补充新制造的蓄电器。任一方向堵满或断供，最终都会让循环停下，即使两颗星球看起来仍有不少库存。

适用情况

  • 远程采矿星缺乏合适的本地电源；
  • 集中发电已很充裕；
  • 双向运输蓄电器，比运输燃料并维护发电机更简单。

何时返回主线

按星球的实际情况选择更简单的系统。几台本地发电机，仍可能比一套漂亮却没人需要的星际电池交换系统更实用。

[高级采矿] — 大型远程采矿网络

用途

让大型跨星球采矿网络建得更快，少些重复操作。

适用情况

  • 已有许多远程采矿星在运作；
  • 逐台铺设采矿机和汇集传送带，占用了建立前哨的大部分时间；
  • 依托星际物流站的采矿网络已经成熟。

做法

把它当作工厂已经遍布多颗星球之后的便利升级，而不是提前铺开的理由。

不确定问题出在哪里时

看不懂工厂为什么停下来时，先别凭直觉重建。按顺序问自己：

  1. 这项科技能研究吗？
    不能的话，查看还缺哪项前置科技。

  2. 这个配方或这台机器能造吗？
    不能的话，查看是否还缺另一项科技，或缺少实际执行配方的机器。

  3. 所有必需材料，都能持续供应吗？
    不能的话，找出还无法可靠开采、生产或输入的那种材料。

  4. 这条线还依赖我搬运或手动喂料吗？
    如果是，就把缺失的运输或仓储环节自动化。

  5. 能找到产品最先停住的地方吗？
    从需要的物品开始，沿生产流程逆向追查。找到第一台缺料、产出堵塞、没电，或运输连接不送货的机器。工厂分布太广、难以目视追踪时，参考生产统计操作示例。修复这一处，让产线运行，再检查结果。

操作速览 — 用生产统计查找短缺

示例：黄糖研究正在进行，黄糖仓储也没满，但矩阵生产变慢了。

先看这三个数值

查看 含义
生产速率 所选时间段内，实际生产的速率。
参考速率 已建成并接入电网的设备，在理想条件下能达到的产量。
仓储数量 判断停产是否只是因为产物已无处可放。

1 — 找出变慢的产物

  1. 按 P，选择生产统计，范围选统计当前星球，时间选1 分钟。
  2. 搜索结构矩阵。
  3. 比较它的生产速率与生产侧的参考速率。
  4. 判断故障前，先悬停查看仓储数量。产出仓储已满，说明产线在等待，并非发生故障。

2 — 追查缺失的供应

  1. 如果仓储未满，而且研究正在消耗矩阵，点击上游原材料生产统计，比较金刚石和钛晶石。
  2. 如果钛晶石这一行表现偏低，就向上追一步，查看有机晶体和钛块。
  3. 注意：母星的钛块来自输入，而非本地生产。
  4. 把范围从母星切换为其所属的星系名称。行星视图会把跨过其边界的钛块计为输入；星系视图包含源头行星的生产，并把星系内部行星间的运输视为内部流转。

3 — 确认并修复

  1. 切换到10 分钟，判断短缺是否持续存在，而不只是最近一次送货间隙。
  2. 根据各行显示的情况，继续追查钛块的上游，或检查星际物流路线。
  3. 修复一个原因，让路线运行，再检查结果。

面板详解

统计范围
查看眼前工厂时，选择统计当前星球；工作跨越同一星系的多颗行星时，按名称选择对应的星系；后期需要工厂全貌时，再选统计全星区。
时间区间
用1 分钟快速查看近期变化，用10 分钟查看更平稳的短期平均值。历史区间的数据是每分钟平均值；总计显示的则是累计数量。
物品行
每行包含生产和消耗及其各自的参考速率、输入与输出、相关物流仓储、仓储总量、垃圾数量、历史曲线，以及直接跳转原料和产物的入口。
范围边界
输入和输出指跨越所选统计范围边界的运输，与边界内的生产和消耗不同。
参考速率
这是统计范围内，符合条件且接入电网的设施，按当前配置计算出的理想产能。计算会考虑配方、机器速度、增产模式、研究加成及相关设施行为。它不是实际产出、历史平均值，也不是你设定的目标。
悬停详情
悬停参考速率可查看设施明细，悬停仓储数量可查看物品存放位置，悬停历史曲线可查看确切的时间段和数值。
实时刷新
右键点击任一圆形刷新箭头，可持续刷新参考速率和当前库存快照。这不会替换所选历史区间，也不会把生产和消耗变成瞬时速率。

面板能说明什么：它能找出表现不足的环节。仅凭与参考速率的差距，无法确定具体原因究竟是缺料、产出堵塞、电力不足，还是其他运行限制。修改之前，先检查对应的实体产线。

每次只修复一处看得见的停滞。机器安静下来、产出已满，说明它在等待，并非故障，也无需扩建。
